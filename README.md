## 👋 About Me
Full-stack developer with 2+ years of hands-on experience learning and building projects, focused on creating practical web applications with clean code and collaborative problem-solving.

My work covers designing component systems, structuring state for maintainability, securing auth flows, and tuning performance so pages load quickly. I enjoy owning the full stack, from Express backends to Next.js/React frontends.

I've collaborated with other developers on team projects and made contributions to numerous open-source repositories.
